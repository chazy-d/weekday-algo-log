# Day 06 — 무인도 여행

- 날짜: 2026-09-09 (수)
- 문제: [프로그래머스 — 무인도 여행](https://school.programmers.co.kr/learn/courses/30/lessons/154540)

## 태훈

- 결과: AC 
- 소요 시간:30분 
- 생각 또는 막힌 지점: 처음에는 위·왼쪽 칸을 기준으로 섬을 구분하고 set에 좌표를 저장하는 방식을 생각했다. 하지만 이미 존재하는 두 섬이 나중에 하나로 연결될 때 어떤 섬에 합쳐야 하는지 관리하기 복잡했다. 한 칸에서 상하좌우로 이동하며 연결된 모든 땅을 방문하면 섬 하나가 완성된다는 관점으로 BFS를 사용했다.
- 다음에 확인할 점: 2차원 맵에서 “상하좌우로 연결된 영역”, “섬의 개수·크기·합계”가 나오면 BFS/DFS를 먼저 떠올린다. 큐에 넣는 순간 visited를 표시해야 같은 칸이 여러 번 들어가지 않는다. 따라서 queue 활용 떠올리기.
