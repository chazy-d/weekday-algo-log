# Day 04 — 2 x n 타일링

- 날짜: 2026-09-07 (월)
- 문제: [프로그래머스 — 2 x n 타일링](https://school.programmers.co.kr/learn/courses/30/lessons/12900)

## 태훈

- 결과: AC
- 소요 시간: 30분
- 생각 또는 막힌 지점: 초반에 일반적으로 구할수는 없어보여 규칙성을 찾으려고 했고, dp를 사용해서 점화식을 세워보았다. 근데 여기서 내가 처음 떠오른 점화식은 2*dp[n-3]+dp[n-2] 구조 였는데, 주어진 n이 10^9로 최악으로 점화식 계산시 3*10^9에 가까워져 int의 최대 표현 가능값은 약 21억 이므로 오버플로 에러가 뜨게 되었다. 다른 점화식을 찾거나 리턴 값을 더 러프하게 잡아줘야할 것 같아서 Long Long으로 변환후 리턴해주니 통과하였다.
- 다음에 확인할 점: 최대 표현 가능 값, 다른 점화식으로는 표현 불가능 한지.
- 참고: 재귀보단 점화식 반복..
